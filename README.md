# 🎯 STL Generator with QR Code

Онлайн генератор 3D моделей (STL) с встроенным QR-кодом и текстом для 3D печати.

## ✨ Возможности

- 📐 Настраиваемые размеры основного блока
- 🔲 Автоматическая генерация QR-кода из текста
- 📝 Встраивание текста с настраиваемым шрифтом
- 🎨 Гибкое расположение элементов (QR слева/справа/сверху/снизу)
- 🎯 9 вариантов выравнивания текста
- 👁️ 3D предпросмотр в реальном времени
- 💾 Экспорт в STL формат для 3D печати
