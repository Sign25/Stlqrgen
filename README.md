# 📋 Техническое задание и документация
## STL Generator with QR Code для Bambu Lab X1C

---

## 📌 Общее описание проекта

**Название:** Продвинутый STL генератор с QR-кодом и текстом  
**Назначение:** Веб-приложение для создания 3D моделей табличек с QR-кодом и текстом для двухцветной 3D печати  
**Целевой принтер:** Bambu Lab X1C  
**Материалы:** 
- Основа: белый PLA
- QR-код и текст: черный PLA-CF

---

## 🎯 Основные требования

### 1. Архитектура файлов STL

1.1. **Раздельные модели:**
- Итоговый результат - два отдельных STL файла
- Первый STL - основной блок (белый PLA)
- Второй STL - QR код и текст (черный PLA-CF)
- Файлы должны быть совмещены в пространстве

1.2. **Позиционирование:**
- Верхние поверхности первого и второго блоков на одном уровне
- QR и текст выступают над основой на настраиваемую высоту

1.3. **Формат файлов:**
- Бинарный формат STL (не ASCII)
- Оптимизация для слайсера Bambu Studio

### 2. Пользовательский интерфейс

2.1. **Поля ввода размеров:**
- Ширина основного блока (мм)
- Высота основного блока (мм)
- Толщина основного блока (мм)
- Высота QR и текста над верхним уровнем основного блока (мм)

2.2. **Настройки текста:**
- Поле ввода текста (многострочное)
- Размер шрифта (ручной или автоматический)
- Автоматический подбор размера текста (чекбокс)
- Разрешение переноса текста на следующую строку (чекбокс)

2.3. **Настройки QR-кода:**
- Автоматическая генерация на основе введенного текста
- Размер модуля QR-кода
- Уровень коррекции ошибок:
  - 5% - Низкая (L)
  - 7% - Средняя (M)
  - 10% - Повышенная (Q)
  - 20% - Высокая (H)

2.4. **Расположение элементов:**
- Позиция QR-кода (слева/справа/сверху/снизу/по центру)
- Выравнивание текста (сетка 3x3)
- Отступы QR-кода от края
- Отступы текста от края
- Расстояние между QR и текстом

### 3. 3D визуализация

3.1. **Окно предпросмотра:**
- Размер: 25% от окна пользователя
- Позиция: правый нижний угол
- Фиксированное положение при прокрутке

3.2. **Функции просмотра:**
- Автоматическое вращение модели
- Ручное вращение мышью (останавливает автоматическое)
- Масштабирование колесиком мыши
- Переключение видов (все/основа/QR/текст)
- Сброс вида

3.3. **2D предпросмотр:**
- Отдельная область с видом спереди
- Отображение в виде масштабированной картинки
- Показ реального QR-кода после генерации

### 4. Техническая реализация

4.1. **3D объекты:**
- QR-код состоит из отдельных 3D кубиков (не текстура)
- Текст состоит из отдельных 3D блоков для каждой буквы
- Реальная геометрия для правильного экспорта

4.2. **Сохранение конфигураций:**
- Запоминание настроек в localStorage
- Сохранение/загрузка/удаление конфигураций
- Именование конфигураций

4.3. **Экспорт файлов:**
- Три отдельных кнопки скачивания:
  - base_white_pla.stl (основа)
  - qr_black_pla_cf.stl (QR-код)
  - text_black_pla_cf.stl (текст)
- Бинарный формат STL

## 🛠️ Технологический стек

### Используемые библиотеки:
- **Three.js r128** - 3D визуализация и работа с геометрией
- **QRCode.js** - генерация QR-кодов
- **Vanilla JavaScript** - основная логика без фреймворков
- **HTML5 Canvas** - работа с 2D графикой

### Требования к браузеру:
- Поддержка WebGL
- Поддержка localStorage
- Современный браузер (Chrome, Firefox, Safari, Edge)

## 📐 Настройки для Bambu Lab X1C

### Рекомендуемые параметры печати:
- **Высота слоя:** 0.2 мм
- **Заполнение:** 20%
- **Скорость печати:** Стандартная
- **Диаметр сопла:** 0.4 мм
- **Температура PLA:** 210°C
- **Температура PLA-CF:** 220°C
- **Высота элементов над основой:** 0.6-1.0 мм

### Процесс печати:
1. Загрузить оба STL файла в Bambu Studio
2. Назначить материалы:
   - Белый PLA → основа
   - Черный PLA-CF → QR и текст
3. Выровнять модели (автоматическое совмещение)
4. Запустить печать с автоматической сменой филамента

## 📝 Инструкция пользователя

### Быстрый старт:
1. Открыть приложение в браузере
2. Ввести размеры основного блока
3. Ввести текст для QR-кода
4. Выбрать расположение элементов
5. Нажать "Генерировать модель"
6. Скачать STL файлы
7. Загрузить в Bambu Studio
8. Начать печать

### Советы по использованию:
- Используйте высокий уровень коррекции ошибок (20%) для надежного сканирования
- Оптимальная высота элементов: 0.8 мм
- Минимальный размер QR-модуля: 2 мм для читаемости
- Сохраняйте успешные конфигурации для повторного использования
- Проверяйте 2D предпросмотр перед экспортом

## 🐛 Известные ограничения

1. **Размер текста:** При очень длинном тексте может потребоваться ручная корректировка
2. **QR-код:** Максимальная длина текста ограничена возможностями QR
3. **Браузер:** Требуется поддержка WebGL и современные веб-стандарты
4. **Память:** При очень детальных моделях возможно замедление
5. **Мобильные устройства:** Интерфейс оптимизирован для десктопа
